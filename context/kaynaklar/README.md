# Kaynak kullanımı

`kaynak-indeksi.md`, kullanıcının sağladığı dosyalar ve araştırmada kullanılan bağlantılar için kayıt yeridir. Ham dosyayı izin olmadan değiştirme; gizli veriyi kopyalama. Bir iddiayı kaynakla ilişkilendirirken erişim tarihi, yayıncı, gerçek içerik ve uygulanacağı ürün kararını kaydet. Rakip pazarlama iddiasını bağımsız doğrulanmış sonuç gibi sunma. Tasarım ilhamı, lisanslı bileşen ve kendi fikrimiz ayrı belirtilir.
