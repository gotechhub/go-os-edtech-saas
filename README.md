## Yerel çalışma

```powershell
corepack pnpm install
corepack pnpm check
corepack pnpm dev
```

Web uygulaması varsayılan olarak `http://127.0.0.1:3003/tr` adresinde çalışır. Gerçek müşteri verisi veya gizli anahtar repoya eklenmez.
