# Respongo OS çalışma noktası

- Tarih: 2026-09-30.
- Aktif amaç: Özel S3 karantina → tarama → yayın zincirini tamamlayıp ilk GOLMS SCORM yüklemesine bağlamak; paralelde gerçek giriş/davet/MFA ve HQ/Control Center ince dilimini sürdürmek.
- Korunan taban: V1/V2 ayrı tarihsel depoda kalır. Bu çalışma alanı yalnızca temiz `go-os-edtech-saas` Respongo OS kaynağıdır; aktif kod depo kökündedir ve `v3/` katmanı kaldırılmıştır.
- Gerçek durum: SCORM ingestion, kesin 1.2/2004 edition, GOLMS asset köprüsü, değişmez yayın worker'ı ve gerçek Supabase/S3 worker adaptörleri; tek kullanımlık launch bileti, ayrı-origin player oturumu, path-safe içerik proxy'si, temel `API`/`API_1484_11` adaptörü, suspend/resume state ve program raporu yerelde hazırlandı. Yönetici içerik kütüphanesi; kalıcı taslak-yükleme eşlemesi, hak beyanı, doğrudan S3 ZIP yükleme, temiz durum sorgusu, bağlama ve açık yayın onayıyla eklendi. Öğrenen listesi sunucu tarafından belirlenen sıradaki adımı başlatır; sıralı program ön koşulu RPC'de yeniden doğrulanır. `202609270004` ve `202609280001`–`202609280005` migration'ları hosted ortamda henüz uygulanmadı.
- Yerel doğrulama: 2026-09-30 tarihinde TypeScript, 15 test dosyasında 81 test ve Next production build geçti. PGlite tenant/idempotency/lease/yayın kapısı, yönetici/öğrenen ve tenant ayrımı, süresi biten denemede yazma engeli, launch replay/expiry/wrong token/path traversal, runtime sıra/idempotency, state resume, program ön koşulu, worker lease kimliği ve idempotent S3 yayınını kapsar. Asset aktarım aracı 11 prefix ile dry-run geçti; canlı AWS değişikliği yapılmadı.
- Hosted temel: `go-os-edtech-saas` GitHub `main` dalı oluşturuldu. Üç V3 migration yeni Supabase projesine uygulandı ve yerel/uzak migration numaraları eşleşti. Kanonik Vercel projesinin Git entegrasyonu `gotechhub/go-os-edtech-saas` deposuna geçirildi; ortam değişkeni bulunmayan mükerrer `go-os-edtech-saas` Vercel projesi 2026-09-27 tarihinde silindi. Vercel production dağıtımı `READY`; kalıcı URL `https://saas-edtech-platform-360.vercel.app`. `/tr` ve üç GOLMS sayfası 200, güvenlik başlıkları aktif, oturumsuz program API'si 401 döndürüyor. 2026-09-27 canlı altyapı kontrolünde üretim sayfası ve Supabase Auth sağlık uç noktası 200 döndürdü; Production/Preview Supabase ortam değişkenleri Vercel'de görüldü.
- Mimari karar: GOAI ayrı ürün/dashboard değildir. Ürün içine gömülü ortak motor ve `goai-ui` sözleşmesidir. Tenant yönetişimi Control Center, global provider/secret/maliyet/eval/rollout Respongo HQ alanındadır. Model yalnız kayıtlı ürün araçlarıyla çalışır; R2–R4 eylemler payload'a bağlı insan onayı ister.
- Sıradaki iş: İçerik kütüphanesinden gerçek referans SCORM ZIP ile özel S3 → tarama olayı → ingestion → immutable yayın → program adımı → atama → player → tamamlama → rapor uçtan uca kabulü yapılacak. Bunun öncesinde paylaşılan eski AWS anahtarı iptal edilmeli; Vercel OIDC rolü, ayrı player host/CloudFront ve malware tarama kararı kurulmalı. Ardından bekleyen depolama ve SCORM migration'ları hosted ortama uygulanacak. Resmî SCORM uyumluluğu ayrıca ADL paketleriyle doğrulanacak.
- Depo düzeni: `v3/` sarmalayıcısı kaldırıldı; `apps`, `platform`, `products`, `standards`, `supabase`, `docs` ve diğer aktif alanlar doğrudan kanonik depo kökündedir. Paket, Vercel, tracker, skill ve bağlantı yolları yeni köke göre doğrulandı.
- Dış bağımlılıklar: Sohbette paylaşılmış AWS erişim anahtarı iptal edilmeden kullanılmaz. Canlı Vercel OIDC rolü, GuardDuty/malware maliyet kararı, CloudFront ve müşteri kabulü henüz doğrulanmadı.

Bu dosya oturum özeti, ürün/şema gerçeği değildir. Durum değiştiğinde kısa ve tarihli güncelle.
